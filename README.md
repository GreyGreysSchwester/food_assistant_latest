# README_功能说明文档

本说明书用于描述智能饮食推荐与营养分析系统的功能组成、运行环境以及使用方法，帮助用户快速了解系统并正确使用各项功能。

本项目是一个基于**大语言模型** Agent 的智能饮食决策系统，采用 LangChain + LangGraph 构建多工具 Agent，实现**饮食需求理解、个性化菜谱生成、烹饪指导、营养分析**等功能。
在2.0版本中，进一步加入了**语音输入、二维码分享、双屏展示**等交互能力，使系统不仅具备AI决策能力，也具备实际展示和扫码保存功能。
主要功能包括：
- 双屏展示
- 饮食偏好采集 
- 语音输入
- 个性化菜谱生成 
- 智能烹饪指导 
- 营养分析 
- 营养可视化展示 
- 营养报告扫码导出，长按下载

## 1. 饮食需求理解
该阶段为用户需求采集，支持**选择，文字输入，语音输入**。
进入系统首页后，用户依次填写：
- 偏好口味
- 忌口食物
- 过敏原
- 健康目标
系统会自动保存用户画像。

## 2. 菜谱生成、烹饪指导
饮食需求填写完成后点击**生成食谱**, 系统自动调用Agent生成个性化菜谱。
生成内容包括：
- 菜谱名称 
- 所需食材 
- 制作步骤 
- 烹饪时间 
- 制作难度 

## 3. 营养分析
点击**生成营养分析**,系统自动分析该食谱的：
- 热量 
- 蛋白质 
- 脂肪 
- 碳水化合物 
- 膳食纤维 
- 维生素 
- 矿物质 
结果以Echarts图表形式和文字展示，包括各成分环状图、成分与推荐摄入对比柱状图，曦曦的建议，膳食指南参考。

## 4. 扫码带走
点击**带走**按钮，跳转二维码页面，扫码生成卡片，长按可保存。
卡片内容包括：
- 菜谱生成
- 营养分析
